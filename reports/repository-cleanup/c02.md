# C-02 — Docker dan CI/CD

## Lingkup

- Target Docker `test` tidak lagi menyalin dokumen yang dihapus; template env
  contoh dan konfigurasi upload disertakan untuk test kontrak. Batas memori
  512 MiB hanya diterapkan pada target test (production tetap 128 MiB).
- Referensi aktif ke dokumen lama diperbaiki, termasuk test dokumentasi dan
  script pengujian historis. Catatan eksekusi historis tidak ditulis ulang.
- CI publik menguji Laravel dalam Docker, build frontend dan application,
  unit JavaScript, unit BERT CPU-only/offline, unit RAG dengan embedding fixture,
  tooling KB, Compose config, Pint, actionlint, dan whitespace.
- Test BERT yang benar-benar memerlukan release diberi marker `release`;
  pemilihan eksplisit tidak melewati artefak yang hilang secara diam-diam.
- `checksum.yml` menjadi workflow manual khusus default branch, memakai
  environment `bert-release` dan image privat yang dipatok digest. Tidak ada
  publish image, upload bobot, deployment, atau training.
- Compose, Dockerfile inference BERT/RAG, dependency production, lockfile,
  business logic, model/threshold, dan snapshot KB tidak diubah.

## Blocker dan batas verifikasi

1. **Laravel belum hijau.** Empat test `FilamentAuditObserverTest` gagal pada
   baseline observer yang tidak diubah: redaksi perubahan user, pengabaian
   atribut tidak dikenal/nested, redaksi teks dataset, dan redaksi konten/token
   submission. Observer menyimpan dirty attributes tanpa redaksi yang diminta
   test. Kegagalan direproduksi terpisah; tidak di-skip/dilemahkan dalam CI.
   Perbaikan writer audit perlu tugas aplikasi terpisah dengan persetujuan scope.
2. 25 warning Laravel berasal dari parser HTML `SubmissionProgressPresentationTest`;
   empat test Laravel real-BERT skip karena service tidak tersedia dalam runtime
   test tanpa jaringan. Test BERT/RAG mengeluarkan deprecation warning TestClient
   dari dependency Starlette/httpx.
3. `npm ci` melaporkan lima advisory dependency (3 high, 2 critical). Tidak
   menjalankan `npm audit fix` atau mengubah lockfile di luar scope C-02.
4. Workflow belum dijalankan di GitHub (tidak ada push). Maintainer perlu
   menyiapkan approval/default-branch protection environment `bert-release`,
   variables `BERT_REGISTRY` dan `BERT_RELEASE_IMAGE`, serta credentials pull-only
   sesuai README. Login/pull registry privat belum diverifikasi; ekuivalen
   checksum/smoke sudah dijalankan pada image lokal.
   Suite Python `-m release` (22 test) belum dijalankan; hasil checksum/smoke
   bukan klaim bahwa seluruh suite release telah lulus.
5. Image production inference BERT dan RAG tidak dibangun ulang: BERT memerlukan
   artefak privat, RAG memerlukan download embedding. Konfigurasi keduanya diaudit
   tanpa perubahan. Stack Compose production tidak direcreate dan data tidak disentuh.

Dokumentasi operasional lengkap tetap menunggu C-04. C-03 tidak dikerjakan.
