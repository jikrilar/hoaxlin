## Perubahan dan alasan

[Template PDF](../../resources/views/hasil-pdf.blade.php) kini mandiri dengan A4 portrait, margin 18 mm, white background, evergreen dan tone prediksi yang mengikuti web. Body DejaVu Sans 10 pt, metadata 9 pt dan heading DejaVu Serif 19/14 pt; kedua font tersedia di DomPDF dan benar-benar tertanam. Tidak menggunakan Newsreader/Inter browser, WOFF2, Vite, JavaScript, shell atau komponen web. CSS block/table, wrapping dan page breaks diperiksa dengan renderer aktual.

Label, confidence, jenis input serta pemeriksaan URL memakai `DetectionPresentation` existing. Valid netral, Hoaks danger, abstention warning dengan dua kalimat utuh dan disclaimer prediksi. Confidence bukan angka hero atau persentase kebenaran; null/invalid tetap unavailable, nol sah tetap 0%. Model version ditampilkan sesuai record tanpa tambahan `v`. Tanggal kirim/selesai/generasi mengikuti timezone aplikasi, termasuk fixture WITA untuk mencegah hardcoded WIB.

Input/ekstraksi/terjemahan yang melampaui 1600 karakter diberi penanda cuplikan sebelum teks. Terjemahan dibedakan dari input asli; provider/model/bahasa/pipeline nullable memakai “Tidak tersedia”, bukan asumsi tidak diterjemahkan. Source URL HTTP(S) aman dicetak sebagai teks penuh yang dapat wrap. Media diberi catatan privat tanpa mencetak `media_path`. Penjelasan ready dicetak penuh dengan newline; pending/unavailable/unknown/ready kosong memakai pesan sesuai web dan tidak menampilkan narasi lama. Model penjelasan tetap berasal dari record.

Urutan mengikuti P15: identitas/judul/waktu, prediksi dan batas, skor/model, input/provenance, explanation, footer. Ringkasan pengguna tidak lagi mencetak `raw_scores` JSON, raw processing stage atau inferensi diagnostik. Data tersimpan tidak diubah. Controller tetap hanya mengirim submission/result; evidence baru tidak ditambahkan dan tidak ada referensi buatan. Authorization, final guard, response/download contract, pipeline, classifier, schema, CSV dan dependency tidak berubah.
